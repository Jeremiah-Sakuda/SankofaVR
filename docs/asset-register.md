For each future asset, record its stable ID, purpose, creator/provider, source URL or source revision, licence/permission evidence, permitted modifications and redistribution, attribution, cultural/context review, production changes, runtime format/budget, and visual/audio/device acceptance status.

Treat model/tool terms, generated-output terms, source-image rights and dataset/performer permissions separately. Original web Sankofa audio, visuals and code are not cleared merely by appearing in that repository. Its intro music in particular has no recorded licence and must not be reused. Keep full contracts, raw libraries and restricted source media in appropriate ignored local storage; commit concise rights records and only assets approved for repository inclusion.
