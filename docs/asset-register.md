# Asset register

No runtime assets have been imported or accepted in SankofaVR. The PRD's visual and audio tools are candidates. AI-generated music is excluded.

For each future asset, record its stable ID, purpose, creator/provider, source URL or source revision, licence/permission evidence, permitted modifications and redistribution, attribution, cultural/context review, production changes, runtime format/budget, and visual/audio/device acceptance status.

Treat model/tool terms, generated-output terms, source-image rights and dataset/performer permissions separately. Original web Sankofa audio, visuals and code are not cleared merely by appearing in that repository. Keep full contracts, raw libraries and restricted source media in appropriate ignored local storage; commit concise rights records and only assets approved for repository inclusion.
